# 🚀 Telegram Motivation Bot

Telegram bot written in **Go** 🐹 that delivers daily motivation. 

You will also need a **Telegram Bot Token**. You can get one by messaging @BotFather on Telegram 🤖.

## 🚀 Getting Started

### 1. Clone the Repository
```bash
git clone https://github.com
cd go-tg-motivation-bot
```

### 2. ▶️ Run the Bot
```bash
TELEGRAM_BOT_TOKEN=<TELEGRAM_BOT_TOKEN> go run main.go 
```

## 📦 Deployment

To build a production-ready binary, run:
```bash
go build -o motivation-bot main.go
```
